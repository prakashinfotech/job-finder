## C. Application Process

### Key Features
- One-click apply
- Resume auto-submit
- Employer questions
- Chat with recruiter
- WhatsApp alerts

### Application Tracking Stages
| Stage | Description |
|-------|-------------|
| Applied | Candidate has submitted application |
| Viewed | Employer has opened the application |
| Shortlisted | Candidate moved to shortlist |
| Interview Scheduled | Interview time confirmed |
| Rejected | Application not moved forward |
| Hired | Candidate successfully placed |

## E. Candidate Pain Points & Opportunities

### Existing Issues
| Pain Point | Impact |
|------------|--------|
| Spam jobs | Poor candidate experience |
| Fake recruiters | Trust erosion |
| Low response rates | Candidate drop-off |
| Duplicate listings | Confusion & wasted effort |
| Poor job quality | Irrelevant matches |
| Limited salary transparency | Misaligned expectations |

### Opportunities to Solve
- ✅ Verified employers only
- ✅ Scam detection
- ✅ Mandatory salary range disclosure
- ✅ AI fraud moderation
- ✅ Better job–candidate matching
- ✅ Response SLA enforcement for employers
- ✅ Application quality scoring
