# Employer Flow (Recruiter Journey)

## A. Employer Onboarding

### Signup
- Business verification
- GST / company details
- HR contact
- Company profile
- Industry type
- Hiring scale

### Dashboard Setup
- Team accounts
- Hiring goals
- Credit / subscription purchase
- Candidate filters

---

## B. Job Posting

### Job Form Fields
- Role title
- Description
- Salary
- Skills
- Experience
- Openings count
- Work mode
- Shift
- Benefits
- Screening questions

### Monetization Options
| Option | Description |
|--------|-------------|
| Free listing | Basic job post at no cost |
| Premium boost | Increased visibility in search results |
| Featured placement | Highlighted position on platform |
| Urgent hiring | Badge for time-sensitive openings |
| Walk-in campaign | Promote in-person hiring drives |
| AI calling / screening | Automated outreach to matched candidates |

## C. Candidate Sourcing

### Tools Available
- Candidate search DB
- Resume unlock

- Nearby candidates
- Bulk messaging
- WhatsApp outreach
- Email campaigns

---

## D. Screening Pipeline

### ATS Stages
| Stage | Description |
|-------|-------------|
| New Applicants | Fresh applications received |
| Matched | AI-matched candidates surfaced |
| Shortlisted | Manually or auto-shortlisted profiles |
| Interview | Candidates scheduled for interview |
| Offer | Offer extended to candidate |
| Hired | Candidate successfully onboarded |
| Rejected | Candidate removed from pipeline |

### Automation Features
- Resume parsing
- AI score (candidate ranking)
- Auto-call bot
- Pre-screen assessments
- Interview scheduling

---

## E. Employer Analytics

### Key Metrics
| Metric | What It Measures |
|--------|-----------------|
| Cost per hire | Total spend divided by successful hires |
| Time to hire | Days from job post to offer acceptance |
| Application volume | Total applications received per role |
| Conversion funnel | Drop-off rates across ATS stages |
| Recruiter productivity | Actions and hires per recruiter |
| Source effectiveness | Performance of each sourcing channel |
